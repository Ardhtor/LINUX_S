# LINUX_S

A small public repository for the associated Linux/file material.

## Primary file

The full file is hosted on Google Drive:

[View the file on Google Drive](https://drive.google.com/file/d/13ip0_G8Rfl623esHwecsdBg3FPn3GAXZ/view?usp=drive_link)

For the link to work for people outside the Google account that owns the file, Google Drive must be set to **General access → Anyone with the link → Viewer**.

## Repository contents

This repository also contains the associated image asset stored directly in GitHub.

## Access model

GitHub hosts the public reference point; Google Drive remains the host for the primary file. Changes to the Drive file continue to live at the same link, so the GitHub README does not need to be changed when the Drive file itself is updated.
